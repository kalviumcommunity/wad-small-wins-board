# Small Wins - Kanban board starter (LU48 CSS Positioning)

Static two-file starter used by the LU48 lesson's live CodeSandbox embed.

- `index.html` - the complete board markup (locked; do not change in the lesson)
- `style.css` - plain Grid base layout with NO positioning declarations yet

Students add positioning rules (absolute badge anchor, sticky heading, fixed
toolbar) into `style.css` while reading the learning unit.

Publish to `github.com/kalviumcommunity/wad-small-wins-board` (branch `main`).
Embed URL used in the lesson:
`https://codesandbox.io/embed/github/kalviumcommunity/wad-small-wins-board/main?fontsize=14&hidenavigation=1&module=%2Fstyle.css&view=split`
